# Generador de imágenes personalizadas V4.1

Aplicación web estática autónoma contenida íntegramente en un único archivo `index.html` (HTML5, CSS3, JavaScript, Canvas API, Web Share API y plantilla PNG integrada en Base64), lista para publicar directamente en GitHub Pages sin compilación ni dependencias externas.

## Publicación en GitHub Pages

1. Sube el archivo `index.html` a un repositorio de GitHub (por ejemplo, en la rama `main`).
2. En **Settings → Pages**, selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
3. Guarda los cambios y abre la URL HTTPS asignada por GitHub Pages.
